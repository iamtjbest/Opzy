# Opzy — working agreements

## Git

- **All sprint work is committed on `sprint-1-auth`**, whatever the sprint number. That
  branch backs PR #1 on GitHub. Don't create per-sprint branches, and don't ask which
  branch to use.
- Don't merge `sprint-1-auth` anywhere until the owner explicitly says so.
- Keep the local branch name identical to the remote one, so a plain `git push` works.

## API

- New endpoints require login the same way `/profile` does, unless the sprint doc says
  otherwise.
